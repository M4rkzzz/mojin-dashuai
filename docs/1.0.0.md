# 1.0 更新

- 四个服务器增加统一加载界面，显示总加载进度。
- 修复连接服务器时界面长时间未响应的问题。
- 加入统一客户端入服认证。
- 修复二服汉化资源包未默认启用的问题。
- 四服更新渲染组件，领地地图增加缩放、拖动和键位提示。

## 更新方式

beta10 至 beta16 玩家重新打开统一客户端即可在登录前检测更新，也可点击右上角“检查更新”。本体按文件差异更新；beta16 到本版实测下载约 2 MiB。

新玩家使用 [Windows 安装包](https://launcher-direct.boshan.uk:21708/launcher/1.0.0/chinese-fix/MojinDashuai-Setup-1.0.0-x64.exe)。游戏客户端与 Java 在选服后下载。

四服已启用入服认证，请通过更新后的统一客户端启动游戏，继续使用原来的账号和游戏名。服务器保留原角色、背包和世界数据。旧版或独立启动器连接时会提示使用统一客户端。

四服内容更新为 r4。更新仍保留玩家地图、标点、游戏设置和内存选择；渲染组件所需配置会迁移一次。内容有更新时，左侧显示“需更新”，点击详情页“更新”即可。
