# 魔金大帅 0.1.2-beta.10

已开放内测。[下载 Windows 安装包](https://launcher-direct.boshan.uk:21708/launcher/0.1.2-beta.10/MojinDashuai-Setup-0.1.2-beta.10-x64.exe)，约 53 MiB。启动器更新序号 10，beta.8、beta.9 未激活。

## 本轮修复

- 三服可同时下载，各自显示下载、暂停与运行状态；新增“仅下载”。
- 三服内容和 Java 统一从 124 的 HTTPS FRP 入口下载；断点及任务记录保留，重开后继续。解压、校验和复制在后台执行，按阶段显示字节或文件计数。
- 网络设置明确区分直连、系统代理和手动代理；错误提供阶段、服务与原因，可复制脱敏诊断。
- 登录前检查启动器更新，变化文件单独下载，校验后静默切换。beta.7 首次升级使用一次完整更新包，之后使用差异更新。
- 模组与资源窗口可调整大小，列表滚动，底部按钮始终可见；增加中文分类、空列表与未选中文件状态。
- “检查并修复”显示进度和实际结果，不自动启动游戏；操作取消不再误报成功。
- “导入旧客户端配置”只保留在左下角工具中，设置页移除重复入口，可选游戏设置、地图与标点、资源包与光影、存档与截图；不导入旧客户端模组本体。
- 切换线路静默保存，失败才提示；手动保存设置仍提示结果。
- 新增默认开启、可关闭的“优先独立显卡”，针对实际游戏 Java 设置 Windows 高性能偏好。关闭时恢复本启动器修改前的值，保留玩家之后的手动改动。
- 皮肤可选 LittleSkin，仍使用原有正版或群服账号。超级邀请码允许注册所有尚未被账号绑定的游戏名。

两条游戏线路平级，切换线路不会更换下载服务器。配套 Java 保持魔法金属 8、亡者世界 17、肉丸工艺 Cleanroom + 25；游戏服务器和角色数据不改动。
