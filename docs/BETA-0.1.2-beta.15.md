# 魔金大帅 0.1.2-beta.15

发布准备中；安装包与四服 r2 完成收尾后一起开放。

- 选服大厅整体上移，减少标题上方和卡片之间不必要的留白。
- 修复 LittleSkin 高清皮肤无法显示、仍出现旧正版皮肤的问题。切换来源后同步更新半身头像，查询失败时显示明确原因。
- 标题栏“检查更新”改为可点击文字，去掉边框、底色和图标；有新版时保持绿色提示。
- 四服弃用 Angelica，恢复 Forge 原生渲染与加载画面。旧客户端的加载配置自动恢复，保留其他个人设置。
- 四服补回 Xaero 大地图，默认 **M** 打开；小地图设置 **Y**，新建标点 **B**。已有自定义按键保留。

四服其余模组调整与地图、连锁挖掘结果在内容收尾后补充。移除 Angelica 后不再提供它的渲染优化及光影功能，实际帧率影响尚未量化。

启动器与四服内容分别更新，已有客户端只下载变化文件，继续使用统一 FRP 下载入口。干净 Windows、真实双显卡和 LittleSkin 游戏内画面仍保留未验收记录。
