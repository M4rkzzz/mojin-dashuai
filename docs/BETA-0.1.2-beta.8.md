# 魔金大帅 0.1.2-beta.8

本版发布准备中。安装包地址、哈希、镜像导入及最终安装验收结果在完成后补齐；当前公开版本入口见 [Beta 使用说明](BETA-0.1.2.md)。

## 本次调整

| 项目 | 新行为 |
|---|---|
| 1. 三服下载任务 | 可以同时下载，各自显示准备、下载和暂停状态；暂停、取消一个服务器不影响其他服务器 |
| 2. 游戏运行状态 | 对应服务器显示“正在运行”，退出后恢复启动入口 |
| 3. 网络与诊断 | 默认直连，明确区分直连、跟随系统、手动代理；错误详情显示失败阶段、服务、状态码或连接原因，可检测、复制及导出脱敏信息 |
| 4. 第三方皮肤 | 皮肤面板可选择 LittleSkin，保留微软及群服账号；使用当前游戏名获取皮肤并配置游戏内皮肤模组，失败使用缓存，不阻塞启动 |
| 5. 旧端导入文案 | 统一为“导入旧客户端配置”，未下载的服务器仍需先下载才能导入 |
| 6. 仅下载 | 勾选“仅下载”后只完成该服务器内容和配套 Java 的安装，不自动启动游戏 |
| 7. 超级邀请码 | 可重复注册未被账号绑定的游戏名，包括原先标记保护但尚未绑定的名字；不能占用已有账号的游戏名，也不授予管理权限 |
| 8. 启动器更新 | 每次打开在登录前检查一次，复用未变化文件，仅下载新增或变化的文件，准备完成后自动静默切换；失败保留可用旧版 |

beta.7 升至本版时仍使用其已有的 ZIP 更新流程；本版起具备逐文件差异更新能力。签名、SHA256 与发布序号验证继续保留，账号、游戏目录和玩家设置保持原样。

## 下载与网络

统一服务入口为 `https://launcher-direct.boshan.uk:21708`，使用现有 124 和 FRP。账号、目录、更新清单与客户端下载从此入口访问；游戏内容、依赖库、原版资源、Java 和配置包必须提前存齐至 `/objects/sha256/{sha}`。玩家下载不再逐个访问 GitHub、Maven、Mojang 或 CurseForge，也不在玩家侧切换第三方下载源。

微软官方授权和主动选择的 LittleSkin 皮肤查询仍分别访问对应账号、皮肤服务；它们不作为游戏安装文件来源。河北阿里云与宿迁三网仍是两条平级的游戏连接线路，选择它们不改变统一下载入口。

重开下载时复用已验证的完整缓存，并从 `.part` 保存的位置续传。服务器忽略 Range 时完整重写该文件；短连接提前结束保留已收到的前缀。共享文件在同一启动器的并发任务之间协调，已存在的进度不再当作从零开始。读取长时间无响应时取消本次读取并重试；过期速度显示归零。

## 验证与保留项

已通过下载连续性专项的 8 项测试、并行实例和运行状态的前端检查、静默更新辅助进程握手与失败回退，以及统一镜像的完整来源审计。三份内容清单共 **33,962 个唯一对象、3,967,908,019 字节**；既有服务器文件与保留本地文件均已按 SHA256 匹配，无未解决缺失。审计不替代真实镜像导入及从统一入口安装，后两项在本版最终记录中另列。

继续保留以下未验收事项：

- 未预装 Java 的干净 Windows 环境。
- 新 LittleSkin 来源在三服真实游戏画面中的皮肤显示。
- 本版更新流程的人工窗口操作、真实旧端文件夹选择器交互和数值帧率对比。
- 用户新增的显卡截图反馈：原因尚未确认，未修改 GPU 指定逻辑，也未将其标记为已修复。

本版详细状态见 [`packs/beta8-acceptance.json`](../packs/beta8-acceptance.json)。不将自动化、辅助进程或以往版本的入服记录冒充上述人工验收。
