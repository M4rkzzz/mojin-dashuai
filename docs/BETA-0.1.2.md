# 魔金大帅 0.1.2-beta.15

[下载 Windows x64 安装包](https://launcher-direct.boshan.uk:21708/launcher/0.1.2-beta.15/MojinDashuai-Setup-0.1.2-beta.15-x64.exe)，约 53 MiB。

启动器与安装包使用统一黑白「帅」图标；选服页前三服使用原图标，四服使用空岛场景图标，直接显示河北阿里云、宿迁三网的实测延迟，进入页面时测一次，之后可手动重新测速。绿色为低于 100 ms，黄色为 100–199 ms，红色为 200 ms 以上或不可达；测速中灰色。各整合包主菜单保留。

1. 运行安装程序，选择启动器安装位置，再从桌面“魔金大帅”打开。
2. 使用拥有 Minecraft Java 版的微软账号登录，或使用邀请码注册群服账号。
3. 第一次登录后确认游戏文件保存位置，默认是启动器安装目录下的 `content`，也可另选目录。
4. 选择服务器及河北阿里云 / 宿迁三网线路，点击进入。

初始安装包不含四个整合包或 Java。只下载选择的服务器内容及固定 Java；已经下载的公共资源按哈希复用。两条线路平级，可自动选择或手动记忆。

启动器在登录前检查自身更新。进入大厅时检查游戏内容更新：左侧显示橙色“需更新”，详情页按钮显示“更新”；更新完成后显示“进入游戏”，不会直接启动。地图、截图、存档及个人设置保留，切换线路继续使用对应实例。旧客户端的设置、地图和标点可从左下角“工具”导入：先下载对应服务器，再选择旧客户端目录并导入；同名文件会自动备份。详见 [导入旧客户端](PERSONAL-IMPORT.md)。

群服账号只用于启动器登录。API 0.1.5 起，超级邀请码可重复注册尚未被账号绑定的游戏名，包括原先标记保护但尚未绑定的名字；已有账号的游戏名不能重复占用，也不授予管理权限。
