# 魔金大帅 0.1.2-beta.7

[下载 Windows x64 安装包](http://103.40.14.100:21708/launcher/0.1.2-beta.7/MojinDashuai-Setup-0.1.2-beta.7-x64.exe)，约 53 MiB。

启动器与安装包使用统一黑白「帅」图标；选服页使用各整合包原图标，直接显示河北阿里云、宿迁三网的实测延迟，每 30 秒更新。绿色为低于 100 ms，黄色为 100–199 ms，红色为 200 ms 以上或不可达；测速中灰色。三个服的多人游戏列表图标已生效，各整合包主菜单保留。

1. 运行安装程序，选择启动器安装位置，再从桌面“魔金大帅”打开。
2. 使用拥有 Minecraft Java 版的微软账号登录，或使用邀请码注册群服账号。
3. 第一次登录后确认游戏文件保存位置，默认是启动器安装目录下的 `content`，也可另选目录。
4. 选择服务器及河北阿里云 / 宿迁三网线路，点击进入。

初始安装包不含三个整合包或 Java。只下载选择的服务器内容及固定 Java；已经下载的公共资源按哈希复用。两条线路平级，可自动选择或手动记忆。

| 服务器 | 运行环境 |
|---|---|
| 魔法金属 | Forge 1.7.10 + Java 8 x64 |
| 亡者世界 | Forge 1.20.1 + Java 17 x64 |
| 肉丸工艺 | Cleanroom 0.5.17-alpha + Java 25 x64 |

肉丸工艺不提供 Java 8/17 或 Forge 回退。Java 无需单独安装。

启动器会检查自身更新；游戏内容在进入前检查更新。地图、截图、存档及个人设置保留，切换线路继续使用对应实例。旧客户端的设置、地图和标点可从左下角“工具”导入：先下载对应服务器，再选择旧客户端目录并导入；同名文件会自动备份。详见 [导入旧客户端](PERSONAL-IMPORT.md)。

群服账号只用于启动器登录。API 0.1.5 起，超级邀请码可重复注册尚未被账号绑定的游戏名，包括原先标记保护但尚未绑定的名字；已有账号的游戏名不能重复占用，也不授予管理权限。

此版本用于内测。干净 Windows 尚未验收，已经按用户决定延后，未标记为通过。其他待补充的人工观察见 [后续验收](REMAINING-WORK.md)。
