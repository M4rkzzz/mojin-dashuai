- React + TypeScript 前端：登录、注册、恢复、大厅、三服详情、平级双线路、下载状态、设置；按用户新要求改名「魔金大帅」并扁平化。

- 22 项核心测试通过：签名、路径安全、Java 25 约束、玩家数据保护、下载重试续传、事务恢复。
