# 四服连接优化交付记录

统一端 1.0.2 已发布；自动更新序列 21，内容目录序列 10。完整计划按连接稳定性优先，Zstd 试验独立于本次公共发布。

## 已实现

- 每个域名复用 TTL 感知 DNS 解析器，失败清除对应缓存；已有 DoH 路径复用客户端和 TTL。
- 合并同时发生的同域名探测，固定线路只实际检查选中线路；只首次测速和手动刷新。
- 目录、清单 HTTP 连接池独立于大文件下载，代理变化替换池，正在使用的旧连接不被强制中断。
- 幂等元数据 GET 对短暂网络错误和 502/503/504 最多重试一次，入口不变；登录、注册、票据处理不扩展重试。
- 启动连接可取消、失败后可重试；记录 DNS、TCP、选线、票据、服务端兑换验证、握手、首批区块观察耗时。最多保留 256 条客户端记录，不记录口令、票据或数据包正文。
- MB/VW 本地 TCP 转发记录上游连接耗时、断开原因、双向字节数；没有改写 Minecraft 数据包。
- VW 增加 Forge 1.7.10 事件型 TCP_NODELAY 适配器。检测到 Hodgepodge 时跳过，避免叠加一服已有处理。

## 二服 ZstdNet

固定 1.4.8 Forge 1.20.1，两端等级 3、发送间隔 2 ms、不限速、默认 HUD 关闭、UDP 关闭。测试副本使用全新平坦世界，不复制正式世界和玩家数据。

发现原作者握手调试输出可能含认证后缀，候选包仅把该日志内容改为固定脱敏文本，不改变握手透传。两轮普通压缩和两轮 Zstd 的相同入服/空闲场景，出口字节平均减少 24.49%。详见 packs/network-optimization/zstd-trial.json。

尚未完成 Create、任务、大 NBT、切维度/重连矩阵、两条公共 FRP 线路和 RTT P95/CPU/Tick 比较，因此未在正式二服启用。录用门槛仍为流量减少至少 10%、P95 恶化不超过 5% 与 5 ms 中较大值、无新增认证/解码/掉线问题。
