## #2 切换 LittleSkin 后仍显示正版皮肤

- 状态：启动器预览已随 beta15 发布；游戏内逐服画面尚未新增验收。
- 用户反馈：皮肤来源已选择 LittleSkin，但皮肤弹窗仍显示原正版皮肤，未切换为 LittleSkin 皮肤。截图只能确认启动器预览现象，游戏内是否同步受影响尚未确认。
- 根因：真实查询 `M4rkzzz` 角色和纹理均返回 HTTP 200，皮肤为 1024×512 RGBA PNG。旧版仅接受 64×32 / 64×64；解析失败被缓存层吞掉，账号层又无提示回落到正版皮肤。
- 修改：公开皮肤读取、缓存和半身像绘制支持 64～2048 的二次幂宽度、1:1 / 2:1 比例高清纹理；文件读取上限 2 MiB，保留 PNG 校验。群服上传接口仍保留原标准尺寸限制。选择 LittleSkin 后只使用该来源及其自身缓存；不存在、获取失败、使用旧缓存时在皮肤弹窗显示具体状态。
- 交互：切换来源只触发一次皮肤读取；过期异步响应不能覆盖新来源；LittleSkin 页不显示“管理正版皮肤”按钮。
- 验收：有效 LittleSkin 角色切换后，弹窗预览和侧栏头像同步更新；刷新、重新打开启动器后来源与皮肤一致；缺少角色或获取失败时显示明确结果；逐服核对游戏内皮肤来源。
- 已验证：真实 LittleSkin 1024×512 纹理读取及缓存通过，使用返回纹理完成侧栏和弹窗截图检查。浏览器检查覆盖标准、纤细、旧版及高清皮肤像素，来源切换、重开、缺失、网络失败、同来源缓存和异步旧请求隔离均通过。游戏侧已按所选来源在下次启动时配置 CustomSkinLoader，运行中的游戏未修改。
