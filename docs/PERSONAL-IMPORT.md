# 旧客户端个人数据导入

左下角“工具”选择已安装的服务器，点击“选择旧客户端并导入”。未安装的服务器置灰并提示“下载后才可以导入”，原生接口也会拒绝未安装实例。默认选择游戏设置、地图与标点；资源包与光影、存档与截图按需勾选。

可选择游戏目录、PCL 的客户端根目录或独立版本目录，支持 `.minecraft/versions/<版本>` 及包裹一层目录的客户端。按三个服务器各自的 Minecraft 版本及实例名称识别；有多个无法区分的实例时要求选择具体目录。

游戏设置包含 `options.txt` 的按键、画面等设置、OptiFine/光影选项、Xaero 配置与 JEI 收藏。模组、服务端控制的整包配置、启动器账号和登录缓存不导入。被替换的当前文件先备份到实例的 `.hub/personal-import/<时间编号>/previous`，导入失败回滚已修改文件，旧客户端保持原样。结果页可以打开备份。

地图原目录保留；与服务器域名匹配的 Xaero 地图另存至统一实例的 `Multiplayer_Any Address`，肉丸工艺 JourneyMap 对应 `Command~Line`。只有一个旧地图世界时可自动关联。多个无法识别的地图世界保留原目录。同路径的旧地图区域文件会替换当前文件并备份，不声称合并同一个区域内部的探索记录。

测试覆盖旧设置生效及备份、PCL 根目录识别、Xaero/JourneyMap 当前目录关联、独立资源选择、版本不符和嵌套目录拒绝、导入失败恢复。界面验证包含未安装禁用、切换服务器、取消与导入结果；真实文件夹选择器仍由玩家操作。
