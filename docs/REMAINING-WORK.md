# Beta 后续验收

2026-09-05，内测版更新至 **0.1.2-beta.13**。四服签名目录、启动器更新、账号 API 与下载服务均已接通。前三服保留既有入服、自动连接和切线地图验收；四服完成空缓存完整包安装、Temurin 8u504 启动、真实入服、自动分岛与初始九区块认领，玩家确认画面、移动和背包正常。干净 Windows 仍按用户同意的范围延期，没有将内测记作稳定版完整验收。

| 尚未验收的部分 | 已有验证与边界 |
|---|---|
| 干净 Windows、未安装 Java 的首次使用 | 用户暂时没有另一台电脑或虚拟机；当前电脑的独立空缓存安装与全部配套 Java 使用通过，不能替代干净系统 |
| 群服自建皮肤在游戏内的独立画面确认 | API 模型、纹理、鉴权和隔离测试通过；正版皮肤和逐服皮肤模组运行已验证，自建 API 缺少角色时正确回落到官方皮肤 |
| 原生文件夹选择器及设置中重启按钮的人工交互 | 文件操作、选择器前端状态、更新命令和失败回退测试通过；真实 beta.3 → beta.4 WPF 启动接管通过，未以模拟器结果冒充按钮人工点击 |
| 三服高 DPI 界面缩放画面 | 修补 TipTheScales 后，六组实际补丁类无界面测试和真实差异安装通过；仍需原反馈玩家的高 DPI 屏幕确认 |
| 四服任务、机器和皮肤画面的逐项确认 | 本次确认了空岛、移动和背包；源包冻结内容保留，未冒充这些界面的新一轮目测 |
| 帧率定量记录 | 三服游戏运行正常，肉丸工艺地图、任务书和机器已确认；记录了启动时间及内存，尚无数值帧率对比 |

新版一、二服实例内共用 Xaero 地图，三服两条线路的自动连接复用 JourneyMap 目录。所有原地图保留。本轮是空目录安装，没有导入桌面旧端探索记录；地图与服务器角色存档是两件事。

发布信息见 [Beta 使用说明](BETA-0.1.2.md) 和 `packs/beta-release.json`。正式稳定版仍要求干净 Windows 验收，只有显式 beta 发布允许延后该项。后续无需重复申请本次已授权的内测发布。

beta.7 新增旧端导入：设置替换前备份、地图目录关联、失败恢复与未安装禁用均通过自动化测试；尚未人工操作原生文件夹选择器检查真实旧端导入画面。中文及空格路径专项检查已通过配套 Java 与加载器/本地库加载，未开启游戏渲染，不替代干净 Windows 验收。

## 历史 beta10 验收

beta.10 包含八项修复、统一 HTTPS FRP 下载、维护界面和默认高性能显卡偏好。三服共 33,962 个唯一对象已在 124 完整存放，三服均从空缓存完成统一入口安装、配套 Java 核对和启动参数准备。真实中断后重开复用缓存、单文件 Range 续传与 SHA256 核对通过。

本轮没有再打开游戏窗口，历史入服记录保留。LittleSkin 协议、缓存和配置检查通过，三服实际皮肤画面未验证。高性能显卡偏好已实现并可关闭，14 项隔离测试通过；最初“优先集显”截图的原因仍未确认，也没有将系统偏好当作实际渲染器或帧率验收。

最终发布状态见 [beta.10 记录](../packs/beta10-acceptance.json)。测试客户端与临时包清理被自动审批拒绝，返回原因仅为“blocked by policy”，文件保留待处理。
