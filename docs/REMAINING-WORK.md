# Beta 后续验收

2026-09-05，内测版 **0.1.2-beta.7 已开放**。三服签名目录、启动器更新、账号 API 与下载服务均已接通。三服空缓存下载、配套 Java 安装、真实入服、自动连接和切线地图检查通过。用户已同意先开放内测，保留干净 Windows 未验收记录；没有将内测交付写成完整正式验收。

| 尚未验收的部分 | 已有验证与边界 |
|---|---|
| 干净 Windows、未安装 Java 的首次使用 | 用户暂时没有另一台电脑或虚拟机；当前电脑的独立空缓存安装与全部配套 Java 使用通过，不能替代干净系统 |
| 群服自建皮肤在游戏内的独立画面确认 | API 模型、纹理、鉴权和隔离测试通过；正版皮肤和逐服皮肤模组运行已验证，自建 API 缺少角色时正确回落到官方皮肤 |
| 原生文件夹选择器及设置中重启按钮的人工交互 | 文件操作、选择器前端状态、更新命令和失败回退测试通过；真实 beta.3 → beta.4 WPF 启动接管通过，未以模拟器结果冒充按钮人工点击 |
| 帧率定量记录 | 三服游戏运行正常，肉丸工艺地图、任务书和机器已确认；记录了启动时间及内存，尚无数值帧率对比 |

新版一、二服实例内共用 Xaero 地图，三服两条线路的自动连接复用 JourneyMap 目录。所有原地图保留。本轮是空目录安装，没有导入桌面旧端探索记录；地图与服务器角色存档是两件事。

发布信息见 [Beta 使用说明](BETA-0.1.2.md) 和 `packs/beta-release.json`。正式稳定版仍要求干净 Windows 验收，只有显式 beta 发布允许延后该项。后续无需重复申请本次已授权的内测发布。

beta.7 新增旧端导入：设置替换前备份、地图目录关联、失败恢复与未安装禁用均通过自动化测试；尚未人工操作原生文件夹选择器检查真实旧端导入画面。中文及空格路径专项检查已通过配套 Java 与加载器/本地库加载，未开启游戏渲染，不替代干净 Windows 验收。

## beta.8 本轮记录

八项修复及统一 HTTPS FRP 入口见 [beta.8 说明](BETA-0.1.2-beta.8.md)。并行下载、独立暂停/取消、运行状态、“仅下载”、停滞速度归零、代理选项和诊断复制的前端检查通过；下载连续性 8 项专项测试通过。完整来源审计核对了 33,962 个唯一对象，全部可由 124 保留文件及本地缓存供给，不需要玩家访问第三方安装文件来源。

本版镜像实际导入、单入口真实安装和最终安装包验收结果由发布记录单独回填；来源齐备并不代表这些步骤已通过。干净 Windows 继续保持未验收。新增 LittleSkin 已有协议、缓存和客户端配置测试，三服游戏内的实际皮肤画面仍需确认。

显卡截图反馈目前原因不明。启动代码没有新增指定 GPU 的参数或系统显卡偏好修改，不能称为已修复；需结合实际 Java 进程和游戏画面进一步确认。
