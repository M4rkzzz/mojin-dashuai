魔金大帅 1.0 启动诊断包

1. 将 ZIP 完整解压到一个新文件夹，不要直接在压缩包里运行，也不要覆盖原安装目录。
2. 双击“启动诊断.cmd”，等待约 40 秒。即使没有主程序窗口，也请等待报告生成。
3. 将桌面上的 Mojin-Startup-Diagnostics-日期时间.zip 发给管理员，并说明有没有出现主程序窗口。
4. 如果普通诊断没有反应，可关闭本次打开的主程序后，再双击“兼容模式诊断.cmd”，也把它生成的 ZIP 发回。
5. 如果稍后才出现错误，双击“收集日志.cmd”重新生成报告。

不需要登录或下载游戏。兼容诊断仅对本次进程跳过更新等待、使用软件渲染和独立显示缓存，不修改系统显卡设置。
诊断版不会自动切换到其他启动器版本；缺少 WebView2 时会记录并提示，不自行安装。
日志不包含账号文件、浏览器资料、游戏存档或内存转储。
程序本身包含 .NET 运行环境。请在 Windows 10/11 x64 上运行。

若诊断窗口本身也打不开，请截取弹出的 Windows 提示，并告知 Windows 版本。
